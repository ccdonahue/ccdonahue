# Wearable Data Science & Biomedical Informatics

I'm a postdoctoral researcher and certified athletic trainer with a PhD in Kinesiology, specializing in adolescent concussion recovery, sleep health, and wearable technology.

My research integrates clinical expertise with computational approaches to understand how sleep, physical activity, and physiological regulation evolve during recovery.

## Research Interests

- Wearable sensing and digital health
- Sleep and circadian health
- Adolescent concussion and recovery
- Intensive longitudinal data analysis
- Reproducible biomedical research

## Computational Projects

My GitHub repositories demonstrate a reproducible workflow for processing, analyzing, and visualizing longitudinal wearable data.

**[Wearable Data Preprocessing](https://github.com/ccdonahue/wearable-data-preprocessing)**

Reusable Python functions for cleaning, restructuring, and quality-checking wearable data exports.

**[Wearable Feature Engineering](https://github.com/ccdonahue/wearable-feature-engineering)**

Python tools for deriving participant-level summary statistics, temporal trends, within-person variability, and circular sleep-timing features.

**[Longitudinal Wearable Visualization](https://github.com/ccdonahue/longitudinal-wearables-visualization)**

Reusable visualization functions for individual trajectories, between-participant heterogeneity, missing-data patterns, and multivariable wearable measurements.

## Technical Skills

**Programming:** Python, pandas, NumPy

**Scientific computing:** Longitudinal data processing, feature engineering, data quality assessment, circular statistics

**Visualization:** Matplotlib, participant-level trajectories, missingness heatmaps, multivariable figures

**Reproducibility:** Git, GitHub, Jupyter, pytest, modular Python development

## Data and Reproducibility

All public demonstration datasets are synthetic. These repositories illustrate generalizable computational methods without exposing identifiable participant data or unpublished study-specific analyses.
